# Platform Services Status Page Notifications

This repo primarily acts as an approval system for alerts to let them be reviewed before posting. To standardize posting these notifications to the MS Teams #Openshift-alerts channel, the best way is to use the template, or repurpose a recent existing one. Then in Visual Studio Code, press the preview button at the top right on the window. That will convert the markdown to RTF which looks better when posted in MS Teams. You can also view the file directly in Github as an RTF if needed.

Suggested filename format: `YYYY-MM-DD_CGH1234.md`
