# Platform Services Status Page Notifications

This repo primarily acts as an approval system for alerts to let them be reviewed before posting. To standardize posting these notifications to the MS Teams #Openshift-alerts channel, the best way is to use the template, or repurpose a recent existing one. Then in Visual Studio Code, press the preview button at the top right on the window. That will convert the markdown to RTF which looks better when posted in MS Teams. You can also view the file directly in Github as an RTF if needed. At times these notifications may be used by the Platform Team to send email notifications, so be aware of that potential usage.

Suggested filename format (based on the date the notification is created, not when the activity is happening): `YYYY-MM-DD_CGH1234.md`
